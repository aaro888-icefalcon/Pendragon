# Seed Sources — Arthurian Britain   (hook: seeds)
- deck size: 35            # 30–40
- refresh: each bookkeeping (and a full rebuild at Winter Phase)
- sources (Pendragon canon and live state lead; generators add novelty):
  - **the current year brief** — hooks, scheduled events, and NPCs of the active year
    (`campaign/uther/` for 480–495, `campaign/gpc/` for 496–566). The strongest source.
  - **ingested adventure clusters** near the PC (`adventures/uther-adventures.md`) — so
    Expected Scenes can be framed from authored Pendragon content (then Scene-Tested).
  - **live state** — open objectives in `state/threads.md`, recurring people in
    `state/npcs.md`, and any "Divergences" recorded in `state/campaign.md`.
  - **random rolls for novelty**, on (see `generators/registry.md`):
    - `generators/adventure_seeds_all.json`            # one-roll adventure premise
    - `generators/complications_sudden_complications.json`  # a wrinkle / reversal
    - `generators/npcs_type_freeman.json` (or _gentry/_underclass by locale)  # a new face
    - `generators/sites_ruin_tags.json` / `generators/communities_community_tags.json`  # a place
- consumed when a seed is invoked by a scene / Turning Point / Random Event; then refresh.

# The seed deck is the gap-filler's pantry, not the plot: it never overrides the year
# brief or a thread that is already due. Pendragon canon outranks a random seed.
