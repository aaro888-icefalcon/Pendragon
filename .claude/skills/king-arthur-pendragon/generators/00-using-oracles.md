# Using These Oracle Files

**Scope:** Guidance for the AI Game Master on when, how, and how not to use these generator tables in a Pendragon campaign set in Arthurian Britain.

**Use when:** You need to improvise a court, faction, NPC, site, community, religion, adventure hook, or complication on the fly — or when you want to pre-generate material between sessions without over-preparing.

**Procedure:** Roll dice honestly using code execution. Record what you rolled vs. what you selected for thematic reasons in a brief build log note. Interpret results in the fiction of dark-ages Britain; do not force a result that breaks the genre.

---

## The Core Commitment

Two rules govern every oracle roll in this collection:

1. **Player-established lore is fixed.** If a player has named a lord, described a manor, or spoken of a feud, that is canon. Oracles fill the gaps around that canon; they do not overwrite it.

2. **Roll honestly; interpret boldly.** The dice provide a direction. The GM provides the meaning. A result of "poison or curse" on a court problem table becomes a whispered scandal about the Earl's wife; the oracle gave the theme, the fiction gave the face.

---

## When TO Roll

- **Improvising on the spot.** A knight rides to an unplanned manor. Roll 2 Court Tags, a "Who Runs It?" result, and a "Current Pressing Problem." You have a scene in 60 seconds.
- **Between sessions.** Use the Faction Turn rules (02-factions.md) to advance off-screen political events. Roll Faction Goals and check them honestly.
- **When you have no strong preference.** If you don't care who the suspicious steward is, roll the NPC quick-gen table. The dice often surprise you into something better than what you'd have invented.
- **When the world needs to breathe.** Not every NPC should be a custom creation. A d12 roll on the Specific Warriors table gives you a serviceable man-at-arms in 10 seconds.

## When NOT TO Roll

- **When the drama is already in motion.** If the players are mid-confrontation with an established villain, don't roll for complications. Let the scene breathe.
- **When a result would require retconning established facts.** If you've already told the players this village is prosperous, don't roll "Fallen Prosperity" on the community table.
- **When you want to pick.** Picking is always allowed. The tables are inspiration scaffolds, not mandates. Roll when you want surprise; pick when you want craft.
- **For major named NPCs already established.** Don't randomly re-roll a named lord's motivations mid-campaign. Use the NPC tables to generate new characters, not to overwrite existing ones.

## Dice Conventions

These files use standard polyhedral notation:

| Die | Range | Common use |
|-----|-------|------------|
| d4 | 1–4 | Temple size, small details |
| d6 | 1–6 | NPC quirks, relationship age |
| d8 | 1–8 | Court major figures, ambitions |
| d10 | 1–10 | Faction checks, obstacles |
| d12 | 1–12 | Community figures, problems |
| d20 | 1–20 | Religion portfolio, NPC traits |
| d100 / d00 | 1–100 | Tag selection tables |

For d100: roll two ten-sided dice, one as the tens digit and one as the units digit. A result of 0-0 = 100.

**To simulate any die roll:** Generate a random integer in the die's range. Do not "pick randomly" by judgment — execute actual random generation.

## Interpreting Results in Arthurian Britain

These tables were derived from *Worlds Without Number* (WWN), a post-apocalyptic fantasy game. Every table has been reskinned for dark-ages Britain, but some entries require a moment's interpretation:

| WWN concept | Arthurian equivalent |
|-------------|---------------------|
| Ancient Working | Roman engineering, faerie enchantment, or holy relic |
| Arratu wasteland | Blighted fenlands, haunted moors, or the Perilous Forest |
| Blighted tribe | Wild Pictish reavers, enchanted forest folk, or cursed outlaws |
| Outsider / alien | Fey, giant, or Old-World demon |
| Sorcerer | Enchanter, wise woman, Merlin-figure, or hedge-witch |
| Automaton / construct | Animated guardian, brass warrior, or bound spirit |
| Deep / tunnel system | Barrow, mine, Roman underground complex |
| Magic item / Working | Holy relic, faerie gift, Roman artifact, enchanted blade |
| Demihumans | Faerie folk, giants, talking beasts, Otherworld beings |

When a result still doesn't fit, **replace it** with the nearest Arthurian equivalent. The table length must remain the same so the dice still work.

## The Build Log Habit

After any oracle session, note briefly:
- What you rolled
- What you changed and why
- What you picked instead of rolling

This creates an audit trail for consistency and lets you revisit decisions if the players ask questions.
