# Entourage Members: Full Stat Blocks and Rosters

Complete stats, costs, skills, and generation rules for every follower type: Squire, Wife, Mesnie soldiers, Professionals, Entertainers, Healers, Common Servants, Lady's Entourage, and Maiden-in-waiting.

**Use when:** Creating or adjudicating any specific follower; generating a squire, wife, or soldier; determining what a professional can do.

---

## SQUIRE

### Core Statistics

**Starting Age:** 14. Age increases by 1 each year.

**Squire Skill:** 15 + modifier (from background table below).

**Knightly Skills:** (Age − 11) + modifier. At age 14, base = 3; at age 21, base = 10.

**Loyalty (Lord):** Starts at **15**.

**Upkeep:** £1/year.

### Squire Background Table (d20)

| d20 | Background | Squire Skill Modifier | Knightly Skill Modifier |
|-----|-----------|----------------------|------------------------|
| 1–3 | Esquire's son | -2 | -1 |
| 4–7 | 4th or later son of vassal knight | -1 | 0 |
| 8–12 | 2nd son of vassal knight | 0 | 0 |
| 13–17 | Heir of vassal knight | 0 | 0 |
| 18–20 | Son of estate holder or baron | +2 | +1 |

### Unusual Background Modifiers (apply to d20 result before table lookup, or use directly)

| Background | Squire Skill Modifier | Knightly Skill Modifier |
|-----------|----------------------|------------------------|
| Son of holy man | -4 | -2 |
| Commoner's son | -7 | -3 |
| Foot soldier's son | -5 | -2 |

### Temporary Squires

A knight may engage a temporary squire rather than raising one from age 14.

| Stat | Value |
|------|-------|
| Upkeep | £1/year |
| Squire Skill | 15 (fixed) |
| Knightly Skills | 1d6 + 2 |
| Age | 1d6 + Knightly Skill score + 10 |
| Loyalty (Lord) | 3d6 (rolled; no starting guarantee) |

Temporary squires have no background modifier. Their Knightly Skills are already set at hire and do not start from (Age-11).

### Squire Knighthood and Dismissal

- **Age 21:** A squire who has not been knighted must be released. Each year of service beyond 21: roll 1d20. On a result ≤ years-served-past-21, he departs (e.g., 2 years past 21 = departs on 01–02).
- **Early dismissal:** Costs the knight **3 Honor** unless the squire committed a genuine offense.
- **Knighthood:** Knighting the squire is the normal outcome; grants both squire and lord appropriate Glory (see core rules).

### Squire as Player Character

Attribute generation, skill progression, and starting values follow standard Pendragon character creation with the following adjustments:
- Start at age 14.
- Squire Skill at 15 + modifier.
- Knightly Skills at (Age-11) + modifier.
- Loyalty (Lord) at 15.
- No warhorse; no full armor initially.

## WIFE (Lady of the Manor)

### Core Statistics

**Starting Age:** 14 + 1d6 (roll at marriage, not before).

**Lady Skill (Stewardship modifier):** See table below.

**Starting Skills:**

| Skill | Starting Value |
|-------|--------------|
| Stewardship | 5 + Lady Skill modifier |
| Chirurgery | 5 |
| First Aid | 5 |
| Courtesy | 5 |
| Industry | 5 |
| Intrigue | 5 |
| Flirting | 5 |
| Fashion | 5 |
| Dancing | 5 |

**Annual Skill Improvement:** Chirurgery, First Aid, and Courtesy each improve by +1 per year automatically, up to a maximum of **10**.

**Passion:** Love (Family); starting value from dowry/marriage table.

### Wife's Stewardship Modifier by Father's Class

| Father's Social Class | Lady Skill Modifier |
|----------------------|---------------------|
| Commoner | -7 |
| Foot soldier's son | -5 |
| Esquire | -2 |
| Holy man's daughter | -3 |
| Household knight | 0 |
| Vassal knight | 0 |
| Estate holder / Baron | +3 |
| Officer (admin/court) | +1 |

### Wife and Dowry Table

Roll on the appropriate sub-table based on the knight's social class. The GM adjudicates which table applies.

**Standard Knight's Wife Table (roll 2d6 or GM-selected):**

| Roll | Wife's Origin | Dowry | Dower | Notes |
|------|--------------|-------|-------|-------|
| 2 | Commoner's daughter | None | None | Possible Honor issue |
| 3–4 | Foot soldier's daughter | None | None | Below class; Honor check |
| 5–6 | Esquire's daughter | £1–£5 | Equal to dowry | Modest match |
| 7–8 | Household knight's daughter | £5–£10 | Equal | Appropriate match |
| 9–10 | Vassal knight's daughter | £10–£20 | Equal | Good match |
| 11 | Estate holder's daughter | £20–£40 | Equal | Fine match |
| 12 | Baron's daughter | £40+ | Equal | Exceptional match |

**Dowry:** Cash and/or land given by bride's family to the knight at marriage.

**Dower:** Portion of husband's estate guaranteed to the wife if she is widowed. Set at marriage; typically equals dowry.

### Wife's Glory at Marriage

| Quality of Match | Glory Awarded |
|-----------------|--------------|
| Below class | 0 |
| Appropriate match | 1d6 |
| Excellent match | 2d6 |
| Spectacular match | 3d6 |

### Shortchanging the Wife

If the knight fails to provide appropriate maintenance for his wife:

| Year | Consequence |
|------|-------------|
| Year 1 | Selfish check required (roll vs. Selfish trait; success = knight is noted as selfish) |
| Year 2+ | Selfish check AND Cruel check required each year |
| Any year | -1 Honor per year of shortchanging |
| Income ≤ £1 for wife | Considered an insult to her family; her kin may take action |

### Previous Marriage Assets (Wife)

If the wife is a widow, roll 1d20:

| d20 | Result |
|-----|--------|
| 1–10 | No significant assets from prior marriage |
| 11–14 | Small Glory: +1d6 Glory; no children |
| 15–17 | Moderate Glory: +2d6 Glory; 1 living child (joins household) |
| 18–19 | Significant Glory: +3d6 Glory; 1d3 living children; ex-in-law family is friendly |
| 20 | Exceptional: +4d6 Glory; 1d3+1 children; ex-in-law is a powerful family; possible complications |

### Older Wife

A wife who is **21 or older** at time of marriage:
- Roll on the Previous Marriage table (above).
- Receive the associated Glory from that prior history.
- Her skills may be higher than a young wife (GM sets starting values based on age and history).

## MAIDEN-IN-WAITING (Lady's Supporter)

### Core Statistics

**Starting Age:** 14. Age increases by 1 each year.

**Skills at Start:**

| Skill | Starting Value |
|-------|--------------|
| Industry | 1d6 + (Age − 10), max 15 |
| Courtesy | 1d6 + (Age − 10), max 15 |
| One chosen skill | 1d6 + (Age − 10), max 15 |

**Loyalty (Lady):** Starts at **15**.

**Upkeep:** £1/year.

### Multiple Handmaidens

- The lady's longest-serving handmaiden has a guaranteed position.
- Additional handmaidens are dependent on the lady's economic circumstances.
- Each additional handmaiden costs £1/year.

### Handmaiden Departure Roll

Each Winter Phase, roll 1d20 for each handmaiden **over age 21**:
- **01–19:** She remains in service.
- **20:** She departs (GM determines reason: marriage, nunnery, another household, death, disappearance).

### Releasing a Handmaiden

| Reason | Honor Effect |
|--------|-------------|
| Marries; dismissed to husband's service | No Honor loss |
| Dismissed for genuine dishonor (proven) | No Honor loss; she is sent to nunnery |
| Dismissed for dishonor (false accusation) | Her family becomes enemies |
| Any other reason | Lady loses 1 Honor |

### Handmaidens Over 21

Women who remain unmarried past 21 become **Damsels-in-waiting**. They retain their position but have diminishing prospects for marriage. This is noted for social roleplay; no mechanical change.

## HUSBAND (Lady Player Character)

When a lady is the player character, she may roll for a husband.

### Random Husband Table

Roll with modifiers based on lady's class and situation. Result determines husband's social rank, approximate age, and key stats.

**Modifiers to roll:**
- Lady is daughter of high-ranking lord: +2
- Lady is widow (desirable assets): +1
- Lady is older than 25: -2
- Lady is below class (commoner origin): -3

| Roll (2d6 + modifiers) | Husband's Type | Notes |
|------------------------|---------------|-------|
| 2 or less | Poor foot soldier / esquire | Below class; possible Honor issue |
| 3–4 | Household knight | Standard service knight; no land |
| 5–7 | Vassal knight | Holds a manor (£10) |
| 8–10 | Estate holder | Holds multiple manors |
| 11–12 | Baron / great lord's knight | Major holder; significant match |
| 13+ | Baron or above | Exceptional match |

### Husband Statistics

| Stat | Value |
|------|-------|
| Sword | Varies by age (see table) |
| Lance | Varies by age |
| Horsemanship | Varies by age |
| + 1 additional skill | GM or roll chooses |
| Loyalty (Lord) | 15 |

**Husband's Skills by Age:**

| Age | Primary Weapon Skills |
|-----|-----------------------|
| 16–20 | 10–12 |
| 21–25 | 13–15 |
| 26–30 | 15–17 |
| 31–35 | 16–18 |
| 36–40 | 15–17 (declining) |
| 41+ | 13–15 (declining further) |

### Husband's Dower

The husband provides a dower to the wife equal to a portion of his estate (negotiated at marriage; typically 1/3 of annual income).

### Husband's Glory Table

A husband's existing Glory is determined by his age and career:

| Age + Career | Base Glory |
|-------------|-----------|
| Young knight, limited service | 100–500 |
| Experienced knight, some tournaments | 500–1,500 |
| Veteran, notable deeds | 1,500–3,000 |
| Distinguished, high reputation | 3,000+ |

### Previous Marriages (Husband)

Roll 1d20 if husband is over 25:

| d20 | Result |
|-----|--------|
| 1–12 | Never married; no previous history |
| 13–15 | Widower; no living children |
| 16–17 | Widower; 1 living child (heir issue) |
| 18–19 | Widower; 1d3 living children; prior in-laws friendly |
| 20 | Widower; 1d3+1 children; prior in-laws powerful; possible complications |
