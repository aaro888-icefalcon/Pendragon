# Battle Miscellaneous Rules

Terrain modifiers (complete table), weather effects, night combat, siege rules, naval battles, caltrops, missile fire from non-engaged units, fighting in camp, double/triple opponents, NPC passions, fancy tactics, and scripted events. All mechanical edge cases not covered by the core round sequence.

**Use when:** Any non-standard battle condition arises that isn't covered by the standard 5-step round.

---

## Complete Terrain Modifiers

Terrain modifiers are **optional** (use when players are familiar with the system, or when scenarios specify difficult ground).

Apply Unit Intensity modifiers in Step 2 and Melee modifiers in Step 4.

| Terrain | Unit Intensity Modifier | Melee Modifier | Other Effect |
|---------|------------------------|----------------|--------------|
| Pre-selected equal battlefield | None | None | None |
| Bushes and brush | Mounted Units: +5 | On Foot +5, Mounted −5 | None |
| Cliff (below cliff) | +10 | Missile +5 if atop it | No melee up or down cliff |
| Ditch | +10 | +5 defender, −5 attacker | Crossing requires Climb or Jump; no Charge |
| Earthworks (DV = 2) | None | Defender +10, Attacker −15 | Assault maneuver required; Horsemanship roll to attack |
| Fence or rail | None | None | Crossing requires Climb or Jump maneuver |
| Hedge | None | Spear or missiles only | Crossing requires Climb or Jump |
| Hedgerow | None | No attack possible | No movement across; blocks unit |
| Ladders | None | −15 to climber | Allow assault up walls/cliff |
| Marshy ground | +5 | Mounted Combat −10; No Charge | Horsemanship roll required before melee |
| Muddy ground | +5 | Mounted Combat −5; Lance Charge −10 | −5 to Horsemanship; −10 to Charge bonus |
| Rain | +5 | No missile troops can shoot | −5 to Awareness; may cause muddy ground |
| Ravine or trench | +20 | Below −10, Above +10 | Move along it, or climb out; no Charge across |
| Rise or hill | None | Below −5, Above +5 | None |
| Rocky ground | +5 | Mounted Combat −5 | −5 to Horsemanship |
| Trees, dense stand | Mounted Units: +5 | −5 infantry, or Mounted Combat −10 | −5 to Horsemanship |
| Trees, thin copse | None | On Foot +5, Mounted −5 | −5 to Horsemanship |
| High walls (≥10 ft.) | +5 | Defender +5; Attacker must use ladders | No melee except with ladders; Assault maneuver required |
| Low walls (waist high) | +5 | −5 vs. men behind them (per KAP Cover rules) | Crossing requires Climb or Jump |
| Water (≥1 ft. deep) | None | None | None |
| Water (1–3 ft. deep) | +5 | −10 to infantry, ±0 to mounted; No Charge | −5 Horsemanship; slows individual movement |
| Water (3–4 ft. deep) | +10 | −20 to infantry, ±0 to mounted; No Charge | −5 Horsemanship; slows movement |
| Woods, amidst | Mounted Units: +5 | −5 infantry, or Mounted Combat −10 | −5 to Horsemanship |

**Applying terrain:** The GM announces which zones have difficult terrain before the battle begins. The terrain modifier applies every round the unit is in that zone.

**Multiple terrain types:** If multiple terrain features overlap, apply all modifiers (they stack).

## Battlefield Obstacles

Specific obstacles that impede movement or require special actions to cross:

| Obstacle | Effect |
|----------|--------|
| Caltrops | Scattered on ground; zone affected; Horsemanship roll or horse takes 1d6 damage; lasts until cleared |
| Ditches | Cannot Charge across; must use Climb or Jump skill to cross |
| Earthworks | Must use Assault vs. Position maneuver; cannot Charge through |
| Pilings (water) | Block movement through affected water zones |
| Parapet/rampart | Defender +10; only Assault maneuver works |
| Stakes | Anti-cavalry; lance charge cannot be made into staked position; horse takes 2d6 damage on Charge |
| Pavise (portable shield) | −10 to attacker targeting shield-user (from missile units) |
| Steep incline | −5 Horsemanship; cannot Charge uphill |

## Caltrops

Caltrops are scattered metal spikes that injure cavalry horses:
- Applied to a zone before the battle or by a unit action during battle (requires Remove from Battle / Remain Disengaged action)
- Any unit entering a caltrop zone: Horsemanship roll required
  - Success: horse steps around them; no damage
  - Failure: horse takes 1d6 damage; unit may be Disordered
  - Critical Failure (Fumble): horse takes 2d6 damage; knight potentially unhorsed
- Caltrops remain effective until cleared (1 round of work by a dismounted unit, requires Disengage action)
- Infantry are unaffected by caltrops

## Missile Fire from Non-Engaged Units

When an enemy unit has missile weapons and is not currently Engaged in melee, they may fire at the player unit:

**Trigger Roll:** If player unit is in the same or adjacent zone, roll 1d6:

| Zone Relationship | Fire on Roll of |
|------------------|----------------|
| Same zone | 1–5 (almost certain) |
| 1 zone away | 1–4 |
| 2 zones away | 1–2 |
| 3+ zones away | 1 (unlikely) |

**Missile Resolution:**
- If the trigger roll indicates fire: player knight is under missile attack this round
- Player may split their melee attack to engage the missile unit (halved skill for each)
- Against missile units, Win = missile unit loses, Loss = missile unit wins
- Glory for being shot at = missile unit's base Glory value (even without killing anyone)
- Armor and shield apply to missile damage

**Missile Damage:**
- Bow: 3d6
- Crossbow (light): 1d6+10
- Crossbow (medium): 1d6+13
- Crossbow (heavy): 1d6+16
- Javelin: 3d6
- Compound Bow: 3d6 (range 8)
- Arbalest: 1d6+10 (range 10)

## Multiple Opponents: Double and Triple Attack

Some enemy units are marked ×2 or ×3 in the unit table:

**×2 opponents:** Player knight fights two enemies from the same unit simultaneously
- Divide weapon skill by 2 (round down) for each opponent
- Both results count separately toward unit tally
- Glory: full Glory for each opponent defeated

**×3 opponents:** Player knight fights three enemies simultaneously
- Divide weapon skill by 3 (round down) for each
- All three results count toward unit tally
- Glory: full Glory for each

**Fanatics (×1d3):** Roll 1d3; that many opponents attack the knight this round

## NPC Passions in Battle

Enemy units with Passion listed in their table entry may invoke it during melee:

**Activation:** Roll 1d6 for each round of battle elapsed:
- If any die shows a 6, the NPC has invoked their Passion this battle
- Once invoked, the bonus applies for the rest of the battle
- At round 4 or later: roll 3d6 (one per elapsed round); a 6 on any = passion invoked

**Effect when invoked:** +10 to their combat skill for all remaining melee

**Hate (Enemy):** The most common enemy passion; typically Hate (Britons) or Hate (Saxons) 20
**Fanatic (<<) symbol:** Always checks passion; double frequency of activation; may not be captured

---

## Fanaticism

An enemy unit marked with << (double angle brackets) is Fanatical:
- Checks Passion every round
- If Fanatical, the unit attacks the player knight's horse first (not the rider) on every attack
- Fanatics may not be taken prisoner (they fight to the death)
- No £ symbol; no ransom possible
- Fanatical units have **Death in Battle** passion or equivalent

## Fighting in Camp (Zone 9)

When players reach the enemy camp (Decisive Victory):
- Roll on enemy army table for camp defenders
- Camp defenders are at ×½ (surprised, not battle-ready)
- First knight to reach camp: +25 Glory
- Camp may contain prisoners, loot, and special targets
- Opponents in camp may be rolled on a separate "Camp Defenders" table (GM discretion: typically wounded troops, servants, camp followers, and any units held in deep reserve)

**Optional Rule — Opponents in Camp:** Any enemy that retreated to Zone 8 or 9 may be rolled on the enemy table at ×½ skill. These are routing troops.

## Siege Rules

Sieges are resolved using a modified battle system:
- **Siege Army Intensity** uses the same calculation; add +10 for defenders in prepared positions
- **Assault maneuver** is required for all offensive action against walls
- Defenders use Dropped Rock (wall defense) or Stand Fast maneuvers
- Ladders: −15 to all attackers climbing
- Artillery (siege engines, if present): GM specifies damage per round against walls; no Battle skill roll required

**Siege duration:** If Army Intensity doesn't reach 0 after 5 rounds, the assault fails; defenders win by default. A new assault may be attempted the next day (new setup required).

## Naval Battles

Naval battles use the same Intensity system with modifications:
- Treat each ship as a "zone"
- Zone movement = moving from ship to ship (boarding actions)
- Terrain modifiers: Water penalties apply universally (all knights are effectively fighting in water conditions if ships are close)
- **Boarding action:** A Charge maneuver across planks or grappling lines
  - Charging across a boarding plank: −10 to all combat skills (narrow footing)
  - Success: Unit is now on enemy ship (new zone)
- **Naval-specific opponents:** Sailors fight at ×½ skill (not trained soldiers), except marines (standard skill)
- **Drowning risk:** On a Crush result, knights who are unhorsed in water must roll Horsemanship (dismounted) or begin to drown; First Aid needed if failed

## Night Battles

Night reduces all combat effectiveness:

| Condition | Modifier |
|-----------|---------|
| Partial darkness (dusk, torchlight) | −5 to all weapon skills; −5 to Awareness |
| Full darkness (no moon, no torch) | −10 to all weapon skills; Awareness rolls required to find enemy |
| Flanking in darkness | Not possible (Opportunity Table results 11–18 are negated) |
| Missile fire in darkness | No missile fire possible |

**Night Ambush:** If one side planned and set the ambush (knows the terrain), they fight without darkness penalties; the ambushed side takes full penalties plus Ambush modifiers.

| Heavy rain | +10 Unit Intensity; no missiles; Horsemanship rolls to avoid slipping |

## Scripted Events: Inserting Fixed Modifiers

The GM may use Scripted Events to override or supplement Battle Events for any reason (canonical GPC events, narrative beats, or dramatic necessity).

**Format:** Announce in Step 2 after rolling Battle Events:

> "Scripted Event: +7 to Army Intensity. A unit on your left flank has broken and the Saxons are pouring through the gap."

**Common uses:**
- Reinforcements arrive (−5 to −10 Intensity)
- Betrayal (key unit switches sides): +10 to +15
- Leader killed by scripted event: −10 + standard leader death rules
- Famous last stand: All Intensity reductions this round are doubled
- Weather change: new terrain modifier takes effect

**Combination:** Scripted Event + Battle Events dice roll can both apply in the same round.

## Fancy Tactics (Advanced Optional Rules)

Available when GM approves and players have mastered the basic system:

### Feigned Retreat
- Unit uses Withdraw maneuver deliberately to draw enemy into an ambush
- Requires at least one other allied unit waiting in reserve
- If enemy Follows: the ambushing unit gets +5 to their first attack
- GM sets up the scenario in advance; this must be declared before the round begins

### Double Attack (Split Unit)
- Unit splits in two (minimum 5 knights each half)
- Each half uses a different maneuver against a different target
- Both halves' results are tallied separately
- Combined results apply to Army Intensity (additive)

### Reserve Commitment
- Fresh reserve unit (Disengaged, not yet entered combat) enters battle
- First round as fresh reserves: enemies at ×½ AND −10 to enemy Unit Commander's Battle skill
- After first round: normal combat

## Multiple Units Running Simultaneously

When GM is tracking multiple player-led units:

1. Calculate Army Intensity once (shared resource)
2. Each unit separately: calculates Unit Intensity, rolls Battle, resolves melee
3. Apply each unit's Unit Results to Army Intensity separately:
   - Process in order of Zone position (frontmost first)
   - Each unit's result adjusts the Intensity before the next unit calculates
4. Alone knights always figure their results after all units have resolved
5. A unit that Breaks mid-round doesn't retroactively change earlier results

---

## Determining Army Intensity: Quick Reference

```
Army Intensity = Previous Army Intensity
              + Battle Events (3d6 − 10)
              + Scripted Event modifier (if any)

Unit Intensity = Army Intensity
              + Battle Zone modifier
              + Unit Cohesion modifier
              + Terrain modifier

(Treat 0 or negative Unit Intensity as 1)
```

## Glossary Quick Reference

| Term | Definition |
|------|-----------|
| Alone | Knight separated from unit; +10 own Unit Intensity |
| Broken | Unit destroyed; all members Alone |
| Crush | All knights lost their melee; worst result |
| Disengaged | Out of combat; enables Charge next round |
| Disordered | Confused, disorganized; +5 UI, −10 melee |
| Loss | More than half knights lost melee |
| Recoil | Involuntary 1-zone retreat; causes Disorder |
| Rout | Entire army collapses (AI ≤ 0 for 2 rounds) |
| Triumph | All knights won their melee; best result |
| Win | Half or more knights won; standard success |
