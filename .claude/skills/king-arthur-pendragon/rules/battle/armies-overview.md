# Armies Overview

How to use army tables from the Book of Armies: reading the stat block format, scaling rules, unit type glossary, symbol key, cultural specialty skills, and GPC military timeline.

**Use when:** Selecting an army for a battle, interpreting unit statistics, or determining cultural bonuses.

---

## How to Use Army Tables

Each army has a d20 roll table. Some have a date cutoff: "Before [year], use 1d10; after [year], use 1d20." Entries 1-10 represent the early form; 11-20 the evolved army.

**First Charge (Round 1):** Roll 1d6+14 for all armies — the toughest units are at the front.

---

## Stat Block Format

**Columns:** Roll | Opponent | Combat Information | Armor | MW | Glory

### Combat Information Format

`Weapon (Skill): Damage dice [Charge modifier]`

- `Great Spear (15): 4d6` — skill 15, damage 4d6
- `Lance (18) Charger: 6d6 5` — Lance 18, Charger horse gives 6d6, [5] = +5 charge bonus
- `Compound Bow (20): 3d6 8` — skill 20, 3d6 damage, range modifier 8
- `Spear, Sword (15): 5d6` — both skills at 15, uses best for situation
- When multiple weapons listed, unit uses most advantageous

### Armor Format

`Total AP; Armor type (AP), Shield (AP)` — e.g., `16; Chain (10), Shield (6)` = 16 total

### MW (Major Wound threshold)

Damage must reach or exceed MW to cause a Major Wound and take this unit type out of action.

### Glory

Base Glory value per unit; multiply by personal result (Win ×1, Loss ×½, Crit ×2).

## Symbol Key

| Symbol | Meaning |
|--------|---------|
| ♞ | Mounted; Lance Charge capability; +5 Lance on Charge maneuver |
| £ | Ransom value; can be captured |
| << | Passion listed below; NPC invokes it during melee |
| S | Sprinter; flees on foot; Sprint DEX value listed |
| D | Determined; will not flee |
| F | Flee Fighting; shoot missiles while retreating (mounted) |
| MM | Uses missiles AND melee same round |
| ×2 / ×3 | Player fights multiple opponents simultaneously |
| Note | Special rules below the table |

### Sprint

Unit fights at ×½ while sprinting. Players use Run Down Sprinters maneuver (+5 bonus). Sprint DEX = escape speed threshold.

### Flee Fighting

Unit shoots compound bows while retreating on horseback. "Flee = XX" value = skill threshold to escape per round.

## Naffatin Special Rule

Naffatin throw jars of naptha (incendiary liquid). On a hit:
- Deals 1d20 damage that ignores armor (burning liquid seeps inside)
- Even on a miss by small margin, target may catch fire (GM discretion)

## Alternatives and Notes Sections

Each army chapter has:
- **Army Notes:** Unit-specific special rules marked "Note"
- **Leaders Table:** Stats for enemy commanders faced via Opportunity or scripted event
- **Alternatives:** Optional or exotic unit variants; add variety to repeated encounters
- **Historical Examples:** Flavor context; not mechanical

**Leaders:** Each culture has its own leaders table with Battle skill listed. Use the specific leaders table first; fall back to Generic Noble Leaders (in `05-battle-events-tables.md`) if no culture-specific table exists.
